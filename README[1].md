# Sahana Kirubakaran — Portfolio

AI × Art Fusion personal portfolio.

## Run locally
Open `index.html` in a browser.

## Customize
- Profile/content: `index.html`
- Styling: `css/style.css`
- Interactions: `js/script.js`
- Artwork placeholders: add images to `assets/`
- Replace `#` contact/project links with real URLs.
